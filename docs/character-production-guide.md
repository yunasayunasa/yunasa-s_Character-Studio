# 新規キャラクター制作手順

1. 通常姿勢の高品質マスターを1枚作ります。
2. シルエット、腕位置、向き、隠れていた部位が大きく変わる場合だけ `point`、`crossed_arms` 等の追加マスターを描きます。
3. 各マスターを胴体、頭、髪、袖、アクセサリ等へ分解します。
4. 目、眉、口、頬染め、汗など、マスター間で共有できる小差分を `shared_parts` として1セットだけ作ります。
   目だけの差分には目だけのgeometryを持たせます。全身SVGを `<use>` で複製し、clipで小領域だけを見せる構造はRealtime描画が重くなるため推奨しません。
5. 横顔など共有パーツが合わないマスターに限り専用差分を作り、`masterOverrides` へ対応を記述します。
6. 全パーツに `snake_case` IDを付け、SVG ID、PSDレイヤー名、JSON part IDを一致させます。
7. PSD出力対象には `data-export-part` を明示します。暗黙の親グループを複数レイヤーへ複製しません。
8. `expressions.json` は目・眉・口・effectの組合せ、`poses.json` はmasterと大差分、`motions.json` は汎用tracks、`emotes.json` はeffect組合せとして記述します。
9. パックフォルダをZIP化し、アプリのZIPインポートで検証します。
10. パック追加だけで表情、瞬き、口パク、視線、エモート、ポーズ、PNG/GIF/WebM/PSDを確認します。アプリ本体コードは変更しません。

## 変形か描き直しか

- 共通パーツ/transform: 瞬き、口形、眉、視線、頬染め、汗、軽い頭傾き、呼吸、数pxの揺れ
- 専用マスター/専用パーツ: 指差し、腕組み、大きく手を上げる、身体を反らす、大きな向き変更、新しい部位の露出

無理な変形で輪郭や関節を崩さず、共通化できない例外だけをoverrideにします。

## PSDの構造

PSDは完成画像の便宜的分割ではなく、構造化資産の人間向け編集形式です。レイヤー順は `psdLayers` の上から下、各レイヤーはCanvas全体サイズの透明RGBAです。合成レイヤーはPSDの合成画像領域に保持し、個別partは重複なしで1レイヤーずつ出力します。
